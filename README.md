# Restaurant Database

This project contains a relational database for a restaurant booking system.

## Included
- ER Diagram
- RDM Diagram
- Normalization to 3NF
- SQL script
- Sample data
- Required SQL queries

## Database Tables
- Restaurant
- Customer
- Table_area
- Booking_Status
- Restaurant_Table
- Booking
